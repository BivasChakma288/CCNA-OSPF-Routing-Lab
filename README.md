CCNA– OSPF Routing Lab



📌 Project Overview



This project demonstrates OSPF (Open Shortest Path First) dynamic routing configuration using Cisco Packet Tracer.



🎯 Objectives



Configure OSPF dynamic routing.



Establish OSPF neighbor relationships.



Advertise networks using OSPF.



Verify routing table entries.



Test network connectivity between routers.



🛠️ Tools Used



Cisco Packet Tracer



Cisco Routers



CLI (Command Line Interface)



⚙️ Configuration Commands



router ospf 1

router-id 1.1.1.1

network 192.168.1.0 0.0.0.255 area 0



🔍 Verification Commands



show ip ospf neighbor

show ip route ospf

show ip protocols



✅ Learning Outcomes



Understanding OSPF dynamic routing.



Learning neighbor discovery and route advertisement.



Verifying OSPF routes in the routing table.
